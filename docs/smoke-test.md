# Manual smoke test

Run with `cargo run -p desktop`. Items marked *(MVP)* need features that aren't merged yet.

1. App launches without errors in the log. A window titled "Rusting" opens.
2. Resizing the window works. Minimising and restoring doesn't crash.
3. *(MVP)* The canvas shows its bounds and background. Zooming and panning keep content under the cursor.
4. *(MVP)* Drawing with the brush leaves strokes that survive zoom, pan, and resize.
5. *(MVP)* Add three layers. Drawing on one doesn't change the others. Hiding a layer hides its strokes. Reordering changes the stacking.
6. *(MVP)* A locked layer refuses new strokes.
7. *(MVP)* Add keyframes at frames 1, 5, and 9 with different drawings. Scrubbing shows the right drawing on each frame. Dragging a key in the timeline moves it; dropping on another key is refused.
8. *(MVP)* Play at 12 and 24 fps. Timing looks right and playback loops.
9. *(MVP)* Onion skin shows neighbouring drawings and doesn't change them.
10. *(MVP)* Undo and redo a stroke, a layer add or remove, and a keyframe add.
11. *(MVP)* Save, quit, and reopen. Everything above is preserved. Opening a corrupt file shows an error, not a crash.
12. Fill bucket (`K`): draw a closed shape and click inside it with Fill; it fills with the brush colour, under the lines, with no white edge. Draw a shape with a small gap: "No gaps" says "Area not closed — try a larger gap setting"; "Small gaps" fills it. Clicking a fill with another colour recolours it. Undo/redo, save and reopen keep fills.
13. Layer opacity: drag a layer's opacity field down to 30%; its strokes fade live while dragging. One undo brings back 100%. Type 55 into the field and press Enter.
14. Layer groups: select two layers and press the folder (group) button. A "Group 1" header appears above them, indented. Hiding, locking or fading the group affects both layers (drawing on a member of a locked group is refused). Fold and unfold with the arrow. Drag a third layer between the group's rows to add it, drag a member above the header to take it out, and drag the header to move the whole group. Right-click the header → Ungroup keeps the layers. Undo/redo, save and reopen keep groups.
15. Import: File → Import… (below Export) opens a file dialog that offers PNG and JPEG files. Pick a photo larger than the canvas: it appears centred, shrunk to fit with its proportions kept, on the current layer and frame, selected with the Selection tool. Drag it, scale and rotate it with Transform (`Q`), draw on top of it (lines stay above it), and press Delete; undo brings it back. Import onto an empty frame creates a key there. Importing onto a locked layer is refused with a status message; a non-image file renamed to `.png` shows an error. Export a frame and a video: the picture is in them. Save, reopen: it is still there.
16. Text (`T`): click the canvas and type "Hello, world"; the letters appear in the brush colour with a caret after them, and `B`, `E`, Space and `F` type characters instead of switching tools, playing or fitting. Backspace deletes, Enter starts a second line, `Cmd/Ctrl+Enter` finishes. One undo removes the whole text (and the key, if the frame had none). The "o" and "e" have open holes. Select the text with a click or a box: it moves, scales and rotates as one item, and the eraser cuts it. Change the font size and set the draw order to Behind to type under an existing rectangle. Esc while typing leaves nothing. Typing on a locked layer is refused. Save, reopen and export keep the text.
17. Library: the Library panel is on the right (View → Library and `Cmd/Ctrl+4` hide and show it). Import a PNG: it is listed under Images with its file name, and one undo removes both the picture and the library row. Import it again, then drag its row onto the canvas: an outline follows the pointer and the picture lands centred where you let go, selected; one undo removes it. Right-click → Place on Canvas puts a copy centred on the canvas. Double-click the row, type "Sky" and press Enter; Esc cancels a rename. Right-click → Delete is greyed out while a copy is on any frame; delete the copies (or the frame) and it works, and undo brings the row back. Dragging onto a locked layer shows a no-drop cursor and places nothing. Save, reopen: the library and every placed copy are back, and an unused library picture is still listed. A project saved by the previous version (format 9) with pictures opens unchanged.
18. Objects: set the animation to 18 frames. On two layers draw something different on each of frames 1–12 (one key per frame) and add an empty key at frame 13 on both. Select both layers (`Cmd/Ctrl`+click), drag across frames 1–12, right-click the frames → Convert to Object. A new "Object 1" layer appears above them with a diamond key at frame 1 and an empty key at frame 13, the two layers are empty on frames 1–12, the Library lists "Object 1" under Objects, and scrubbing looks exactly as before. Right-click the empty key at 13 → Remove Key: frames 13–18 show the object's frames 1–6 again, with a tick at frame 13 in the timeline. In Tool Settings choose Play once: frames 13–18 hold the object's frame 12. One undo per step brings everything back.
19. Objects on the canvas: draw two shapes, select them with the Selection tool and press `F8`. They don't move, a new layer holds them as a one-frame object, and the object is selected (outline). Drag it, then press the arrow keys: it moves as one unit, one undo step each. With Transform (`Q`) scale and rotate it by its box. Go to a later frame and drag it: a new diamond key appears there. With the Brush on a frame showing the object, drawing is refused with a status message.
20. Placing objects: drag "Object 1" from the Library onto a timeline cell of another layer: it plays from that frame. Drag it onto the canvas: a new layer is added above the active one with the object centred where you let go. Right-click the Library row: Delete is greyed out while it is placed; remove the placed keys and it works. Double-click the row to rename it. Save, reopen: objects, their keys, Loop / Play once and opacity are back, and export (video and GIF) shows the objects. A project saved by the previous version (format 10) opens unchanged.
21. Motion tweens: draw a ball, select it and press `F8`. Set the animation to 24 frames and remove the object's empty key if there is one, so it shows on every frame. Go to frame 12 and drag the ball to the other side of the canvas: a second diamond key appears at frame 12. Drag across frames 1–12 on the object layer, right-click → Create Motion Tween → Ease In-Out. A purple band with an arrow runs from frame 1 to 12. Scrubbing moves the ball smoothly, slow at both ends, and play shows the same. Go to frame 12, scale the ball up with Transform (`Q`), set its opacity to 30% in Tool Settings, and rotate it: frames 1–12 grow, fade and turn smoothly. In Tool Settings on frame 6, switch Motion tween to Linear, Ease In and Ease Out and scrub each. On frame 6, drag the ball down: a new key appears at frame 6 exactly where you dropped it (no jump), and the tween now runs 1 → 6 → 12. Convert an animated object (smoke test 18) and tween it the same way: it keeps playing its frames while it moves. Right-click inside a tween → Remove Tween: the ball holds still until the next key. Right-click a drawing layer's frames: no Create Motion Tween item. Remove the key at 12: the band turns into a dashed line, and Tool Settings offers Remove Tween. Undo brings each step back. Save, reopen: the tweens and their eases are back. Export a video and a GIF: the ball glides. A project saved by the previous version (format 11) opens unchanged.
22. Dockable panels: the panels open as before (tools left, canvas, Library and Tool Settings right, timeline below), each with a tab title except the canvas. Drag the Library tab onto the bottom half of Tool Settings: a highlighted preview shows the drop, and the Library ends up under Tool Settings in one column. Drag the line between them to resize. Drag the Timeline tab onto the left edge of the canvas, then onto the middle of Tool Settings (it becomes a second tab there; click the tabs to switch). Draw on the canvas, pan and zoom it, and drag a Library picture onto it: everything lands under the pointer. Resize the window: only the canvas changes size. `Cmd/Ctrl+4` hides the Library and the canvas grows; pressing it again brings it back in the same place and size. View → Reset Panel Layout restores the original layout with every panel shown. Rearrange the panels, hide the timeline and quit: the next launch opens with that layout. Put an invalid `panel-layout.json` in the configuration folder (on macOS `~/Library/Application Support/Rusting`): the app starts with the default layout and logs a warning.
